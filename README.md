AUREL – Fashion E-commerce Website

AUREL is a React-based fashion e-commerce website designed with a minimal and elegant look. It offers a simple shopping experience with different clothing categories.

Features

- Home page with hero section and editorial banners
- Product listing with different categories
- Search products by name and category
- Filter products by category and maximum price
- Sort products by price
- Product details page
- Add to Cart functionality
- Wishlist functionality
- Login and Signup pages
- Shopping cart with total price

Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- React Router DOM

How to Run the Project

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

npm install

5. Start the project:

npm run dev

6. Open the local URL shown in the terminal.
